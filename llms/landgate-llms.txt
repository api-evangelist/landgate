# Landgate

> Landgate is the Western Australian Land Information Authority — the state agency that keeps the WA land titles register, values every rateable property in WA, and curates the state's foundational location data. Its API surface is split in two and the split matters: an anonymously callable public tier (SLIP ArcGIS REST + OGC WMS/WFS, and the Data WA CKAN catalogue Landgate operates for the whole WA public sector), and a gated tier (subscription SLIP services, bulk downloads, and the registry itself) reached only after signing a licence. There is no developer portal, no provider-published OpenAPI, no self-service API key, and no MCP server.

This file was generated by API Evangelist on 2026-07-26 from live probes of the Landgate estate. Landgate publishes no llms.txt of its own (/llms.txt returns 404 on every Landgate and SLIP host).

## What you can call without any credential

- [SLIP public ArcGIS REST services directory](https://public-services.slip.wa.gov.au/public/rest/services?f=json): ArcGIS Server 12.1, 65 map services in five folders; authInfo.isTokenBasedSecurity is false. Verified HTTP 200 anonymously 2026-07-26.
- [SLIP server info](https://public-services.slip.wa.gov.au/public/rest/info?f=json): version and auth posture.
- [Example feature query — WA LGA boundaries](https://public-services.slip.wa.gov.au/public/rest/services/SLIP_Public_Services/Boundaries/MapServer/14/query?where=1%3D1&returnCountOnly=true&f=json): returns 139 features.
- [SLIP WMS 1.3.0 GetCapabilities](https://public-services.slip.wa.gov.au/public/services/SLIP_Public_Services/Boundaries/MapServer/WMSServer?request=GetCapabilities&service=WMS): 56 layers.
- [SLIP WFS 2.0.0 GetCapabilities](https://public-services.slip.wa.gov.au/public/services/SLIP_Public_Services/Boundaries_WFS/MapServer/WFSServer?service=WFS&request=GetCapabilities): 38 feature types. WFS lives on the `*_WFS` services only.
- [Data WA CKAN Action API](https://catalogue.data.wa.gov.au/api/3/action/status_show): 2,872 datasets, 395 published by the `landgate` organization.
- [Data WA dataset search](https://catalogue.data.wa.gov.au/api/3/action/package_search?fq=organization:landgate&rows=10): Landgate's own datasets.
- [Data WA DCAT catalog (JSON-LD)](https://catalogue.data.wa.gov.au/catalog.jsonld).
- [MyLandgate OpenID Connect discovery](https://sign-on.app.landgate.wa.gov.au/.well-known/openid-configuration) and [OAuth 2.0 authorization server metadata](https://sign-on.app.landgate.wa.gov.au/.well-known/oauth-authorization-server): real PingFederate metadata, but this is sign-on for accounts, not a developer API.

## What you cannot call

- SLIP subscription services (https://services.slip.wa.gov.au/arcgis/rest/services) — HTTP 401 anonymously, even /arcgis/rest/info. Requires a signed SLIP subscription, publication, broker, distributor or value-added-reseller licence.
- Bulk downloads (https://data-downloads.slip.wa.gov.au/) — returns a redirect page to /Account/Login; a MyLandgate/SLIP account is required.
- The authoritative registry record — titles, tenure, ownership, sales evidence, valuations — is not on any public API.

## Traps an agent should know

- The SLIP ArcGIS REST surface returns **HTTP 200 with an `error` object** when something fails. Check the body, not the status.
- `catalogue.data.wa.gov.au` returns **HTTP 200 with a 20KB HTML page for every unknown path**. A 200 there is not proof a document exists — check content-type.
- Open platform does not mean open data: **371 of Landgate's 395 catalogued datasets carry `license_id: custom_other`**, a Landgate licence, not an open licence. Two are public domain; five are CC non-commercial.
- WFS requests against a non-`_WFS` map service return HTTP 400.
- A WFS `GetFeature` with `count=1` returned 1.65 MB on 2026-07-26 — do not assume server-side limiting.
- RESO does not apply here. It is a North American MLS standard and is absent from this Australian government registry.
